# AMA Session

1. **Which property is used to load an image in the background?**
   * The background-image property is used in CSS to set one or more background images on an element (e.g., background-image: url("image.jpg");).

2. **Which selector is used to select a direct child in CSS?**
   * The child combinator (>) selects elements that are direct children of a specified parent element (e.g., div > p).

3. **What is the difference between space-around and space-between?**
   * **space-between:** Places the first and last items flush against the edges with equal gaps between items.
   * **space-around:** Adds equal space around every item, leaving half-sized gaps at the outer edges.

4. **What is the use of pass in Python?**
   * pass is a null placeholder statement that does nothing when executed, preventing syntax errors in empty functions, loops, classes, or conditional blocks.

5. **List some comments in Python, SQL, and HTML.**
   * **Python:** # single-line and """ multi-line """
   * **SQL:** -- single-line and /* multi-line */
   * **HTML:** <!-- single or multi-line -->

6. **What is the difference between the color and background properties?**
   * **color:** Sets the foreground color of text and text decorations.
   * **background:** A shorthand property that styles the area behind an element's content and padding (such as background color or image).

7. **What is align-self?**
   * align-self is a Flexbox/Grid property applied to an individual child item to override the container's align-items alignment along the cross-axis.

8. **What is the full form of HTML and CSS?**
   * **HTML:** HyperText Markup Language
   * **CSS:** Cascading Style Sheets

9. **Does Python support multiple inheritance?**
   * Yes, Python supports multiple inheritance, allowing a class to inherit from more than one parent class and resolving conflicts using Method Resolution Order (MRO).

10. **List the different types of position in CSS.**
    * **static:** The default value; the element follows the normal document flow and ignores offset properties (top, right, bottom, left).
    * **relative:** Positioned relative to its normal position without removing it from the document flow.
    * **absolute:** Removed from the normal document flow and positioned relative to its nearest positioned ancestor (or the initial containing block if none exists).
    * **fixed:** Removed from the normal flow and positioned relative to the browser viewport, staying in the same spot even when scrolling.
    * **sticky:** Acts like relative until a specified scroll threshold is met, at which point it sticks in place like fixed.

11. **What is the difference between align-items, align-content, and align-self?**
    * **align-items:** Aligns all items within a single flex/grid line along the cross-axis.
    * **align-content:** Aligns multiple wrapped lines along the cross-axis when extra space is available.
    * **align-self:** Overrides align-items for one specific individual item.

12. **What is the difference between em and rem?**
    * **em:** Relative to the font-size of its direct parent element.
    * **rem:** Root em; always relative to the font-size of the root <html> element.

13. **What is the difference between id and class attributes?**
    * **id:** Unique to a single element per page and targeted in CSS with a hash (#).
    * **class:** Reusable across multiple elements on a page and targeted in CSS with a dot (.).

14. **What is a class in CSS?**
    * A CSS class is a reusable selector (prefixed with a dot, e.g., .box) used to apply the same styling rules to multiple HTML elements sharing that class attribute.
